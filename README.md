# 最后十席 · 感染区撤离

一款末日题材的轻量化“搜打撤 + 小队养成 + 房车建设”网页游戏。

玩家带领幸存者驾驶一辆受损房车穿越感染区。每回合选择三人行动组，配置现有装备，在外围、内部和核心区域逐步搜索物资，并决定继续深入还是携带战利品撤离。

## 核心玩法

- **小队养成**：最多容纳十名幸存者，十种职业在战局内外持续提供支援。
- **搜打撤行动**：搜索被遮盖的格子物品，与感染者和 AI 队伍争夺资源。
- **风险决策**：搜索时间越长、区域越深入，遭遇、伤亡和装备丢失风险越高。
- **资源循环**：装备、生存物资、房车零件、奢侈品和电脑硬件各有长期用途。
- **房车建设**：维持全队饱食度与健康，修复关键模块，最终撤离感染区。
- **收集系统**：人员与物资图鉴、传奇人物、专属红色道具、黑市与搜救招聘。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

默认访问 `http://localhost:3000/`。

## 构建

```bash
# Vinext / Cloudflare 版本
npm run build

# GitHub Pages 静态版本
npm run build:pages
```

源码保存在 `main` 分支，静态网页发布在 `gh-pages` 分支。
